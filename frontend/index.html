Keyboard Shortcuts

  • ← / → : scrub one step back / forward
  • Home / End : first / last instant
  • Space : play / pause auto-scrub
  • n / p : next / previous line (step into, either way)
  • o / O : step over, forward / backward (skip nested calls)
  • f / F : run to this frame's exit / back to its call
  • / : focus the query box
  • ? : toggle this overlay
